# Flip Frenzy 🎮

**A fast-paced neon arcade game for Android — free to play, with no ads.**

Flip Frenzy is a reaction-based arcade game where players tap glowing orbs matching the current target color. The target changes every five seconds, so players must stay focused, react quickly, and build long combos before time runs out.

## ✨ Features

- 🎯 Fast-paced, one-touch gameplay
- 🌈 Neon visuals and changing color targets
- ⏱️ 30-second rounds
- ❤️ Limited lives and combo scoring
- 🏆 High-score challenges
- 🪙 Earnable in-game coins
- 🎨 Cosmetic skins and customization
- 📤 Share scores with friends
- 🚫 No in-game ads
- 📱 Native Android implementation using Kotlin

## 🎮 How to Play

1. Tap **Play Now**.
2. Tap only the orbs matching the target color.
3. Build streaks to increase your score.
4. Avoid incorrect taps and missed targets.
5. Beat your best score and challenge your friends!

The target color changes every five seconds. Stay alert!

## 🛠️ Tech Stack

- Kotlin
- Android SDK
- Gradle
- Native Android Canvas rendering

## 🚀 Build and Run

1. Install Android Studio.
2. Open this project in Android Studio.
3. Install the Android SDK version requested by the project.
4. Sync Gradle.
5. Run the app on an Android device or emulator.

To create an APK, use **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

For Google Play, generate a signed Android App Bundle (AAB).

## 💰 Monetization
